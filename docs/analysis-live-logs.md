# 实时分析日志验收（2026-11-04）

首页和分析详情页共享日志区域。运行任务默认展开，依次显示官方快照、当前policy提供方、草稿阶段；旧Claude/Codex事件仅作历史兼容；提供总耗时、最近事件时间、连接状态、提供方筛选、搜索、跟随开关和文本导出。触碰或向上滚动日志会暂停自动跟随，收到新记录后可点“查看最新”恢复。

每次当前policy提供方使用其受支持的JSON事件流（Codex exec --json或Harness headless --json）；公开事件解析后先脱敏，再写入 SQLite `analysis_logs`。原始输入回显、工具返回和私有思考不进入日志。每15秒的心跳只表示进程仍在运行，不表示模型正在产生有效分析。

每任务保留最近2000条，页面常驻最近600条。刷新后从保留记录重新读取，增量接口仅 admin 可访问，响应禁止缓存，下载为纯文本。已失败的旧任务没有原始过程记录，因此只能显示原有耗时和结果。

验证包含真实模拟子进程退出前的可见事件、10秒超时后的进程组清理和事件保留、当前policy提供方最终响应解析、隐私过滤、有界保存、游标分页和权限。历史最小调用记录不代表当前提供方真实赛事全链路成功，未调用赛事分析、未发布推荐。
