# 015 逐场分析展示

用户要求除最终二串一外有逐场分析。关联Issue #5。

- 首页每场足球/篮球均有明确“逐场分析”详情入口。
- 复用研究检查点，同业务日/运动/编号/开球/两队match_key精确匹配最新记录，不按编号误混历史。
- viewer可读简要分析：研究状态/时点、主假设/反证/失败路径/缺口，逐选项玩法名/冻结价/p_mkt、证据分/版本/门禁、理由/机制/风险/撤销；管理员另可看完整23维来源页与任务。
- 无结果标待分析，不模板补造；旧规则版本显著警告、评分按查看时点重算，不当当前推荐；市场与研究冻结价分开。
- GET不启动CLI、不调用写API、不发布。POST研究仍走既有管理员/CSRF/任务去重和014门禁。
- 测试无记录、精准身份、低分、过期、权限、转义和主客顺序；部署现有服务，不自动分析或发送消息。
