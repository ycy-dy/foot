# 018 全页面控制件验收

用户要求检查所有页面按钮功能，异常自修复。Issue #8。

## 验收范围

首页/逐场/分析列表与任务/证据/审核发布/每日台账/历史/统计/报告/复盘/计划/监控/撤销/通知/版本/审计/登录退出，通用日期、主题、移动导航、筛选、日志、链接与表单。

按admin/viewer/匿名、空态/已有数据/失败/运行中检查：模板资源装配、实际路由/参数、权限CSRF、必填校验、提交忙碌/错误、防重复、请求结果和持久状态。自动计划/消息通知未授权不得启用，禁用控制须明确原因，不冒称功能已开启。

隔离假身份/来源/CLI/投递测试，不创建生产登录凭证，不误发钉钉/发布原票/重复真实AI；生产仅只读健康、静态资源/可访问页面检查。浏览器受登录/用户切换/环境影响的项明确范围，不能以静态HTTP200认定交互全覆盖。

修复回归后部署现有服务，矩阵列已验证/限定模拟/未验证或政策停用，Issue/台账/commit/push。旧无路由模板属于历史残留，不计活动页面。
