# 任务操作入口

日期：2026-11-05。状态：已实施，验收范围与外部依赖限制见verification.md。

用户要求：今日推荐顶部“Claude分析中”旁可终止；历史推荐可按当前业务日直接复盘并更新结果。

用户补充：分析按钮相当于在本项目调用本机Claude/Codex CLI，提出“请根据最新分析和推荐体系，分析和推荐今天的比赛”。沿用本机账户/默认模型，在项目目录执行，传入明确业务日和本轮冻结的现行体系；逐场检查点与最后AI取舍都是这项总任务的阶段，不用程序模板代替实际AI返回。

验收：

- 管理员在首页与分析详情顶部可见“终止分析”；运行时可点击，正在终止时禁用重复提交，结束后隐藏。调用已有CSRF保护的取消接口，清理CLI进程组并保留检查点。
- 历史页有原票且业务日不晚于今天时，管理员可直接“复盘并更新结果”。复用现有实际Claude/Codex复盘、官方结算、原票冻结与台账提升流程。
- 历史页展示所选业务日的最近复盘状态；运行时显示进度入口，成功后自动刷新结算。待定不算输，失败不替换上个成功版本。查看者仅可读。
- 桌面与375px均可操作，没有整页横向溢出；不为测试终止生产任务或发起真实赛事分析/发布/通知。
