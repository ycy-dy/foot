# Feature Specification: 分析任务实时日志

**Created**: 2026-11-04 | **Status**: Implemented
**Input**: “请优化分析的交互UI，我希望时刻看到智能体 Claude 或者 Codex 的日志。”

## 目标与范围

管理员在今日推荐和分析详情页可以连续查看同一任务的真实执行事件，区分快照准备、Claude 调用、Codex 回退和草稿保存。提供耗时、最近输出时间、连接状态、按提供方筛选、跟随最新及日志导出。

沿用原有单任务门禁、CLI 权限、默认模型、超时配置和草稿隔离。此功能不改变推荐规则或自动发布。旧失败任务未保存的原始过程日志不能补造。

## 验收

- 两种 CLI 以原生 JSON 事件模式运行，退出前即可采集初始化、公开文本、网页工具、警告、错误及结束事件。
- 日志在 SQLite 按任务有序保存，刷新、切换页面、提供方回退及任务结束后仍可查看。每条最多 4000 字，每任务保留最近 2000 条；接口分页读取，页面限制常驻条数。
- 不保存用户输入回显、凭证、完整环境、原始工具返回或模型私有思考内容。先脱敏再落库，前端按纯文本显示。
- 无输出时仅展示真实等待时间和进程存活信息，不伪造进度、百分比或模型活动。
- 日志查询、导出与现有分析状态接口一致，仅 admin 可访问，无缓存；不为长连接占用 Web 线程。
- 首页和详情页每秒增量同步，断线可重连；终态继续取完最后一批日志后停止轮询。日志滚动不干扰用户阅读旧事件，移动端无整页横向溢出。
- 自动化验证覆盖真实模拟子进程在退出前的可见事件、回退/超时保留、隐私过滤、分页权限及刷新恢复；桌面/移动浏览器实测后，运行全量测试并重启服务，健康检查通过。
