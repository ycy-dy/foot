# 035 分析按钮与业务日状态一致性

用户2026-11-09指出当天未开始分析却显示重新分析，要求梳理并优化相关逻辑。关联Issue #8。

## 验收契约

- 无本业务日任务：开始分析；仅有其他日期任务不算当天分析历史。
- 排队：等待分析，禁止重复提交；运行：当前提供方分析中；取消处理中：正在终止。
- 已有研究尝试/检查点或成功草稿的终态：重新分析；未执行就取消：开始分析；未执行就启动失败/中断：重试分析。部分完成的继续分析沿用原续跑门禁，不等于新建任务。
- 初始HTML和真实analysis.js使用相同服务端action契约，刷新/轮询/提交/失败/取消后不得跳回错误文案。
- 全局同时一项分析约束保留；相同任务重复请求复用，其他业务日请求409并明确忙碌任务，不返回冒充当天的新任务。跨任务resume也不得冒充已继续。
- viewer无写按钮；不启动生产付费AI/发布/通知，不改原票、政策门槛或旧工件。
