# Feature Specification: 控制台 UI 优化

**Created**: 2026-11-04 | **Status**: Implemented
**Input**: 用户要求“请优化UI”。

## 范围

在现有 Flask 控制台上优化导航、信息层级、表格和移动端体验。不修改推荐算法、概率、审核门槛、授权或历史数据。

## 用户场景与验收

- 桌面用户可通过固定侧栏访问今日推荐、历史、台账、统计、报告和管理员日志；当前导航有明确状态。
- 手机用户可展开导航、滚动面板标签，推荐内容不挤压、页面不出现整页横向滚动；宽表格只在自身容器滚动。
- 今日页保留已发布汇总优先、市场候选与正式推荐的区分、全部六个面板、快照与风险提示。
- 标签页支持方向键、Home/End、URL hash 和返回导航；筛选为原生按钮，有选中与空状态。
- 支持系统配色及持久化的用户深浅色选择；存储受限时仍可使用。
- 刷新操作有加载、成功与失败反馈；viewer 不显示管理员操作。
- 保留“不下单，不保证命中或收益”和市场基准概率声明。

## 视觉与交互

- 视觉主张：中性色工作台、白色内容面、绿色操作强调，使用排版和细分隔线呈现稳定、紧凑的信息层级。
- 内容计划：导航与日期 → 场次与月度数据 → 六个工作面板 → 汇总或候选明细 → 风险声明；不增加营销区或装饰性图片。
- 交互主张：短暂的面板切换反馈、按钮加载反馈、移动导航展开；尊重 reduced-motion。
- 复用服务端模板，Lucide 图标本地托管，不引入前端框架和运行时 CDN。

## 验证

pytest 覆盖模板语义、权限、空数据和静态资源；使用固定官方快照渲染页面，在桌面与手机视口检查截图、横向溢出、主题和标签交互。测试通过后按现有部署流程重启并检查 healthz。
